# Sepehr Money World — Art Direction v0.1

## هدف
ظاهر بازی باید در اولین نگاه «بازی ماجرایی کودک» دیده شود، نه صفحه آموزشی، داشبورد یا HTML کارت‌محور.

## سبک پیشنهادی
- 2D stylized game art
- شهر نیمه‌ایزومتریک یا top-down با عمق بصری
- فرم‌های نرم و خوانا
- شخصیت‌های کوچک با Silhouette واضح
- جزئیات کافی برای حس دنیا، بدون شلوغی
- UI گیمی با Icon، Meter و Tooltip کوتاه
- انیمیشن‌های کوتاه و پرانرژی برای Coin، XP و Unlock

## شخصیت اصلی
سپهر باید Avatar اصلی باشد، اما برای نسخه اول نیازی به شبیه‌سازی چهره واقعی او نداریم. Avatar قابل شخصی‌سازی ساده بهتر است:
- مو
- لباس
- کیف
- یک آیتم همراه

## NPCها
### Money Bot
- کوچک، دوست‌داشتنی، نه شبیه دستیار اداری
- نمایش احساس از طریق چشم/صفحه صورت

### Fox Merchant
- باهوش، بانمک و کمی شیطنت‌آمیز
- نباید ترسناک یا «شرور» باشد

### Banker
- شخصیت رسمی اما گرم
- ظاهر بانک نباید حس فرم اداری بدهد

## World
### میدان شهر
مرکز حرکت بین Levelها و مشاهده Unlockها.

### فروشگاه
قفسه، قیمت، صندوق و حرکت Coin باید کاملاً Visual باشد.

### بانک
موجودی، واریز، برداشت و قرض از طریق اشیای داخل محیط و دیالوگ انجام شود، نه فرم‌های جدولی.

## HUD
HUD حداقلی:
- Coin balance
- XP
- Quest marker
- Backpack/Wallet

نباید Skills یا گزارش آموزشی روی صفحه کودک نمایش داده شود.

## Parent-only data
Skill score، ضعف/قوت و جزئیات Learning Evidence در UI کودک پنهان است و بعداً در Parent View نمایش داده می‌شود.

## انیمیشن‌های ضروری MVP
- Coin gain/loss
- XP gain
- Quest complete
- Unlock building
- NPC attention marker
- Wallet update

## چیزهایی که ممنوع‌اند
- صفحه سفید با Cardهای متعدد
- Emoji به‌جای Asset اصلی
- متن‌های چندپاراگرافی
- جدول آموزشی در UI کودک
- Progress bar شبیه LMS
- دکمه‌های بزرگ با متن «درس بعدی»
