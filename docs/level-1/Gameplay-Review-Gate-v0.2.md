# Level 1 — Gameplay Review Gate v0.2

## Gate قبل از کدنویسی
این سند باید قبل از Implementation جدید تأیید شود.

### تجربه مورد انتظار
بازیکن باید احساس کند:
- وارد یک شهر کوچک شده
- آدم‌ها نیازهای واقعی دارند
- می‌تواند آزادانه بگردد
- اطلاعات ارزش دارد
- منابع محدودند
- راه‌حل را خودش پیدا کرده

### چیزهایی که نباید احساس کند
- در حال حل تست چندگزینه‌ای است
- بازی یک جواب از قبل تعیین‌شده را از او می‌خواهد
- هر NPC فقط یک پنجره متن است
- انتخاب اشتباه یعنی Game Over
- هدف اصلی گرفتن XP است

### معیار Meaningful Choice
هر تصمیم مهم:
1. حداقل دو State را تغییر می‌دهد؛ یا
2. یک فرصت را باز/بسته می‌کند؛ یا
3. روی رفتار آینده NPC اثر دارد.

### Minimum Gameplay Depth
- 5 NPC
- 3 مسیر معتبر
- حداقل 1 Side Discovery
- حداقل 1 State persistent
- حداقل 1 Opportunity Cost
- حداقل 1 Time-based consequence
- حداقل 1 Trust-based unlock
- 0 وابستگی اجباری به AI

### Playtest Questions
بعد از تست از سپهر نمی‌پرسیم «چه یاد گرفتی؟»

مشاهده می‌کنیم:
- خودش دنبال اطلاعات رفت؟
- قبل از trade مکث کرد؟
- route دیگری امتحان کرد؟
- بعد از رد شدن معامله Strategy عوض کرد؟
- متوجه شد NPCها چیزهای متفاوتی ارزشمند می‌دانند؟
- بعد از اتمام، خواست دوباره با route دیگری بازی کند؟

اگر پاسخ آخر «نه» باشد، replayability و agency کافی نیست.
